## Sobre este portfólio

Página estática em HTML, CSS e JavaScript puros, sem framework e sem dependências além das
fontes do Google Fonts. Está em português e inglês, com tema claro e escuro, e a seção de
código aberto lê os repositórios públicos direto da API do GitHub.

O idioma inicial vem do navegador e a escolha manual fica guardada. O português está
escrito direto no HTML, então a página continua legível e indexável sem JavaScript.

```
index.html             página
assets/css/style.css   estilos, tema claro e escuro
assets/js/conteudo.js  textos em português e inglês, trajetória e números
assets/js/main.js      idioma, tema, navegação e dados do GitHub
assets/img/            capturas dos sistemas
```

Para mudar qualquer texto, data ou número, basta editar `conteudo.js`. O `main.js`
contém apenas lógica.
